# วิธีเทสโจทย์ที่ 3

ใช้บัญชี role ADMIN เซิร์ฟเวอร์ที่ `http://localhost:3000` และ simulator ที่พอร์ต 8788 ถ้าต้องการเห็นเครื่องออนไลน์

## แดชบอร์ด

1. เปิด `http://localhost:3000/dashboard`
2. ล็อกอินอีเมลแอดมิน
3. ต้องเห็นตัวเลขสรุปและการ์ดเครื่อง
4. ทั้งระบบเปิดอยู่: ปุ่ม **เปิดทั้งหมด** พื้นเขียว
5. กด **ปิดทั้งหมด** แล้ว `GET /api/v1/system/kill-switch` ได้ `{ "enabled": true }` ปุ่ม **ปิดทั้งหมด** พื้นแดง บอท claim งานใหม่ไม่ได้ (409) แต่เครื่องไม่ถูกสั่งดับ
6. กด **เปิดทั้งหมด** กลับ ได้ `{ "enabled": false }`

## อัปโหลด zip

1. เตรียมไฟล์ `.zip` เล็ก ๆ ของตัวเอง
2. บนแดชบอร์ดใส่เวอร์ชัน `1.0.1` เลือกไฟล์ แล้วกด **อัปเดตทุกเครื่อง**
3. แถบแพ็กเกจต้องขึ้นชื่อไฟล์ ขนาด และเวลา
4. `GET /api/v1/bots/packages/latest` ได้ `package.fileName`, `sizeBytes`, `uploadedAt`, `version`
5. ไฟล์ไปอยู่ที่ `data/bot-packages/` เซิร์ฟเวอร์ไม่แตกไฟล์และไม่รัน
6. เครื่องได้คำสั่ง `update` ดูได้จาก `GET /api/v1/bots/bot-01/logs`

อัปเดตเฉพาะเครื่อง: เลือกการ์ดแล้วกด **อัปเดตเครื่องที่เลือก** หรือส่ง `botId` ใน multipart (`bot-01` ได้จาก `GET /api/v1/bots`)

ไม่มีไฟล์ใหม่: `POST /api/v1/bots/update` body `{ "version": "1.0.1" }` ส่งแค่เลขเวอร์ชัน

## log

กด **รายงานผล** บนการ์ด หรือเรียก `GET /api/v1/bots/bot-01/logs` ต้องเห็นคำสั่งล่าสุด พร้อมสถานะ

ตัวอย่างคำขออยู่ใน `http/bots.http`
