ยังไม่ล็อกอินสำเร็จ ยังไม่กรอก UID ยังไม่กดจ่าย ยังไม่ขอ OTP

เขียน selector จากไฟล์นี้เท่านั้น ขั้นที่อยู่ในหัวข้อ «ยังไม่เห็น» ห้ามเดา

## ทางเข้า

1. เปิด `https://www.midasbuy.com/midasbuy/jp/shop`
2. เบราว์เซอร์เด้งไป `https://www.midasbuy.com/midasbuy/jp/` ทันทีหลังนำทาง ต้นไม้หน้ายังว่าง รอให้ร้านโหลดประมาณ 2–3 วินาที
3. การ์ดเกมคือ `div.MidasbuyUI-item_0c8d86` ข้อความ `AGE OF EMPIRES MOBILE` ชื่อซ้ำใน `div.MidasbuyUI-name_b1c30d` บนหน้าเดียวกันมีเกมอื่น (NIKKE, HONOR OF KINGS, PUBG MOBILE) ต้องจับคู่ข้อความการ์ดนี้
4. `element.click()` ที่การ์ดแล้วไปที่  
   `https://www.midasbuy.com/midasbuy/jp/shop/aoem?from=self.midasbuy_saas#/pages/shop/items`  
   แท็บ **ショップ** มีคลาส active `MidasbuyUI-active_afba4c`

พารามิเตอร์ที่ซ้ำใน iframe: `appid=1460000565` `country=jp` `lang=ja` `shopcode=midasbuy`

## แพ็กที่ซื้อได้

อยู่เฉพาะแท็บ **ショップ** การ์ดคลาส `div.MidasbuyUI-b_bd8d9d` ข้อความไม่ติดกันเป็น `99至高コイン` ตัวเลขแยกโหนด

การ์ดที่ตรงโจทย์มีข้อความรวม `99 + 109 最大 110% まで 146円 150円 -2.66%`

- `99` อยู่ใน `div.MidasbuyUI-val_56521a`
- `109` อยู่ใน `div.MidasbuyUI-discount_num_c5a695`
- ราคา `146円` อยู่ใน `div.MidasbuyUI-price_b2a1d4` ราคาขีดฆ่า `150円` คลาส `MidasbuyUI-old_55c658`
- ป้าย `-2.66%` อยู่ใน `div.MidasbuyUI-schedule_601c75`

การ์ดอีกห้าใบบนแท็บเดียวกัน ห้ามกด

| ข้อความการ์ด |
| --- |
| `499 + 549` / `698円` / ขีดฆ่า `720円` / `-3.05%` |
| `999 + 1099` / `1,455円` / ขีดฆ่า `1,500円` / `-3%` |
| `1999 + 2199` / `2,949円` / ขีดฆ่า `3,040円` / `-2.99%` |
| `4999 + 5499` / `7,372円` / ขีดฆ่า `7,600円` / `-3%` |
| `9999 + 10999` / `14,647円` / ขีดฆ่า `15,100円` / `-3%` |

ป้าย `-2.66%` ไม่พอใช้ชี้แพ็ก คนเดียว การ์ด Empire Coins `400` บนแท็บ **購入** ก็เป็น `146円` และ `-2.66%` ต้องเช็กแท็บ **ショップ** พร้อมข้อความ `99` กับ `109` กับราคา `146円`

ตอนยังไม่ล็อกอิน การคลิกการ์ด `99 + 109` ไม่ได้เลือกแพ็ก มันเปิด iframe ล็อกอินแทน สถานะถูกเลือกของการ์ดยังไม่เห็น

## ล็อกอิน

เปิดจากแถบ `Midasbuyにサインインする` ด้วย `element.click()` แล้วได้ iframe

- id: `login-iframe`
- src: `https://www.midasbuy.com/apps/login/home/jp?appid=1460000565&cpsIntercept=0&lang=ja#login`
- `contentDocument` อ่านได้เพราะ same-origin

หน้าแรกในกรอบ หัวข้อ `p.title` = `登録・新規登録`

| คลาส | ข้อความ | ใช้กับบอทนี้ |
| --- | --- | --- |
| `div.game-theme-box-btn.type-aoem` | `ゲームを通じて認証する` | ไม่กด ทางนี้เป็นยืนยันผ่านเกม |
| `div.to-other-login` | `他の方法でサインイン/サインアップする` | กดอันนี้เพื่อไปช่องอีเมล |

`element.click()` ที่ `to-other-login` เปลี่ยนเป็นหน้าอีเมล hash ยังเป็น `#login`

หน้าอีเมลที่เห็นจริง

- ปุ่ม `div.btn.passkey-btn` ข้อความ `Passkeyでサインアップ` ไม่กด
- ข้อความ `既にパスキーをお持ちであることを確認してください。`
- `div.signin` ข้อความ `サインイン` เป็นทาง Passkey ไม่ใช่ฟอร์มอีเมล
- ไอคอนสี่อัน เป็น `img` ใน `div.icon` ไม่กด: `login-aoe` (เกม), `google-innner-icon`, `facebook-inner-icon`, `Discord-Symbol-White`
- ข้อความคั่น `or`
- ป้าย `メールアドレス`
- ช่อง `input[type=email][autocomplete=username]` ไม่มี placeholder อยู่ใน `p.inp.y-input-val` ปุ่มล้างค่าคลาส `i.mds-input_close`
- ปุ่มไปต่อ `div.btn.comfirm-btn` ข้อความ `続ける` สะกดคลาสเป็น `comfirm` จริง
- ปิดกรอบ `div.close-btn` `element.click()` ไม่ปิด ต้องยิง pointerdown จนถึง click ที่ปุ่มนี้ถึงจะปิด

กด `続ける` แล้วมีได้สองทาง

- เบราว์เซอร์ในแชทเคยขึ้น `div.pop-toast` ข้อความ `System busy, Please try again later. (-1)` หน้าไม่เปลี่ยน
- Chrome บนเครื่อง วันที่ 9 ตุลาคม 2026 เวลาประมาณ 23:50 น. ผ่านไปหน้า `p.title` = `Midasbuyにログイン`

หน้า `Midasbuyにログイン` ที่เห็นใน Chrome

| คลาส | สิ่งที่เห็น | ใช้กับบอทนี้ |
| --- | --- | --- |
| `div.back-btn` | ปุ่มกลับ ไม่มีข้อความ | ไม่กด |
| `div.close-btn` | ปุ่มปิด | ไม่ต้องกดระหว่างล็อกอิน |
| `div.mds-label_name` | ป้าย `メールアドレス` | — |
| `input[type=text][autocomplete=on]` | placeholder `メールアカウントを入力してください` มีอีเมลอยู่แล้ว | คนละช่องกับ `input[type=email]` ของหน้าก่อน |
| `div.mds-label_name` | ป้าย `パスワード` | — |
| `input[type=password][autocomplete=on]` | placeholder `パスワードを入力` | กรอกจาก `.env` ห้ามพิมพ์รหัสลงซอร์ส |
| `div.icon-eyes.close-eyes` | ปุ่มรูปตา | ไม่กด |
| `div.keep` มี `div.check` | `ログイン状態を保持する` | ไม่กด |
| `div.password` | `パスワードを忘れた` | ไม่กด |
| `div.btn.comfirm-btn` | ข้อความ `サインイン` | กดอันนี้เพื่อส่งรหัสผ่าน |

ปุ่ม `サインイン` นี้เป็น `div.btn.comfirm-btn` ใน iframe คนละปุ่มกับ `div.signin` ของ Passkey และคนละปุ่มกับ `サインイン` ที่หัวร้าน

เมนูข้างมี `サインイン / サインアップ`, `クーポン`, `注文センター`, `アカウントとセキュリティ` ลิงก์ `注文センター` เป็น `href="#"` กดตอนยังไม่ล็อกอินแล้วกรอบล็อกอินเด้งขึ้น URL ไม่เปลี่ยน

## ยังไม่เห็น — ห้ามเขียน selector

เบราว์เซอร์นี้ไปต่อจาก `続ける` ไม่ได้เพราะ `System busy (-1)` ขั้นต่อไปยังไม่มีหลักฐานจากหน้าจอ

- หน้าหลังกด `サインイン` แล้ว รวมข้อความเมื่อรหัสผ่านผิด
- CAPTCHA
- หัวข้อหลังล็อกอินแล้ว (ชื่อบัญชีแทนคำว่า `サインイン`)
- หน้าต่างผู้เล่นตอนอยู่บนจอ ผลหลังใส่ UID `5250140737488366145` และข้อความเซิร์ฟเวอร์
- สถานะการ์ดแพ็กถูกเลือก และสรุปออเดอร์ก่อนจ่าย
- แถวจ่ายของหน้าเช็กเอาต์ ปุ่ม Pay และข้อความ `セキュリティー支払い`
- หน้า Bitcash, `Pay with MyBitCash`, QR, `Pay with a Nexgen 6`
- หน้าล็อกอิน Bitcash, ช่อง OTP, ปุ่ม `お支払う`
- ใบเสร็จ `請求番号` `お支払い額` `残高` และหน้าประวัติออเดอร์หลังจ่าย

ย่อหน้า «สิ่งที่เห็นบนร้านญี่ปุ่น» ใน `README.md` มาจาก Chrome ที่ล็อกอินไว้รอบก่อน รอบนี้เปิดหน้าเช็กเอาต์ไม่ถึง อย่าเอาย่อหน้านั้นมาเป็น selector จนกว่าจะเปิดหน้าเดิมแล้วจดใหม่
