# 0. เตรียมระบบ (ทำครั้งเดียว)

## รัน

```bash
docker compose up -d
bun install
cp .env.example .env
```

ใน `.env` ต้องมีอย่างน้อย

```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/mydb
USER_AUTH_SECRET=change-me-to-32-chars-minimum!!
SYSTEM_USER_NAME=admin
SYSTEM_USER_EMAIL=admin@example.com
SYSTEM_USER_PASSWORD=P@ssw0rd
BOT_SIMULATOR_URL=http://localhost:8788
```

`WEBHOOK_SECRET` เว้นว่างได้ตอนตรวจบนเครื่อง dev ระบบจะข้ามการตรวจลายเซ็น

```bash
bun run prisma:generate
bunx prisma migrate dev --schema=./prisma
bun run seed:admin
bun run dev
```

เปิด

- API `http://localhost:3000`
- OpenAPI `http://localhost:3000/openapi`
- Simulator `http://localhost:8788/health` ต้องตอบได้ (มากับ `docker compose`)

## สร้างข้อมูลต้นทางใน OpenAPI

### 1) Login แอดมิน

`POST /api/v1/auth/login`

```json
{
  "email": "admin@example.com",
  "password": "P@ssw0rd"
}
```

คัดลอก `accessToken` ไปใส่ Authorize ช่อง `bearerAuth`

### 2) สร้างเกม

`POST /api/v1/game`

```json
{
  "name": "Age of Empires Mobile",
  "status": "ACTIVE",
  "servers": [{ "serverName": "Empire#239" }]
}
```

ได้ `{ "message": "success" }` ยังไม่มี id

`GET /api/v1/game?page=1&limit=10` จด `id` ของเกม เป็น `gameId` (ปกติคือ `1`)

`GET /api/v1/game/1` จด `servers[0].id` เป็น `serverId` (ปกติคือ `1`)

### 3) สร้างแพ็กเกจเดียวที่อนุญาตให้ทดสอบ

`POST /api/v1/package`

```json
{
  "name": "99+109 Coin",
  "amount": 208,
  "price": 146,
  "status": "ACTIVE",
  "gameId": 1
}
```

`GET /api/v1/package?page=1&limit=10` จด `id` เป็น `packageId` (ปกติคือ `1`)

### 4) ออกคีย์บอท

Simulator มักสร้าง `bot-01` ถึง `bot-03` ไว้แล้ว ถ้า `POST /api/v1/bots` ด้วย id เหล่านี้ได้ 409 ให้ข้ามไปออกคีย์แทน

ออกคีย์ (แอดมิน):

`POST /api/v1/bots/bot-04/api-key`

ถ้าได้ 404 ให้ลงทะเบียนก่อน

`POST /api/v1/bots`

```json
{
  "id": "bot-04",
  "name": "Midasbuy Bot 04",
  "deviceName": "PC-04"
}
```

response มี `apiKey` แสดงครั้งเดียว คัดลอกเก็บไว้ ใช้เป็น `x-bot-key` และเป็น `BOT_KEY` ตอนรัน worker

ตรวจว่าเครื่องออนไลน์หลังรัน worker อย่างน้อยหนึ่งครั้ง: `GET /api/v1/bots/summary` (ยังเป็นแอดมิน)

### 5) สมัครลูกค้า

`POST /api/v1/auth/register`

```json
{
  "userName": "dragonknight",
  "email": "dragonKnight1140@gmail.com",
  "password": "P@ssw0rd",
  "confirmPassword": "P@ssw0rd",
  "phoneNumber": "0-2222-3333"
}
```

เก็บ `accessToken` ของลูกค้าแยกจากของแอดมิน ตอนเทสออเดอร์ให้สลับ Authorize เป็น token ลูกค้า
