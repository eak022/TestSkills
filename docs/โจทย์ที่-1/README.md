## กติกาที่ใช้ทุกส่วน

- Base URL คือ `http://localhost:3000/api`
- ข้อผิดพลาดเป็น `{ "code", "message" }`
- ทุกออเดอร์ใหม่ต้องใช้เลขใหม่ทั้งสามค่านี้ ห้ามใช้ค่าตัวอย่างเดิมซ้ำ

| ค่า | ที่ใส่ | ทำไมห้ามซ้ำ |
| --- | --- | --- |
| `orderNo` | body | ได้จาก `POST /api/v1/orders` ของรอบนั้น สถานะต้องยังเป็น `PENDING_PAYMENT` ถ้ายิงจ่าย |
| `x-event-id` | header ของ webhook | ซ้ำแล้วได้ผลเก่า `replayed: true` ไม่ประมวลผลใหม่ |
| `providerRef` | body ของ webhook | เลขอ้างอิงธนาคารห้ามซ้ำทั้งระบบ ซ้ำแล้วได้ 500 |

ตัวอย่างรอบแรกใช้ `evt_001` กับ `bitcash-txn-001` รอบถัดไปเลื่อนเป็น `002`, `003` ตามลำดับ

- ลูกค้าและแอดมินใช้ปุ่ม **Authorize** ช่อง `bearerAuth` ใส่เฉพาะ `accessToken` ไม่ใส่คำว่า Bearer ซ้ำ
- บอทใช้ช่อง `botKey` ใส่ `apiKey` ที่ขึ้นต้น `bot_`
- ถ้าใน dev ไม่ได้ตั้ง `WEBHOOK_SECRET` ไม่ต้องส่ง `x-webhook-signature`
- Worker ที่รันค้างจากรอบก่อนให้หยุดก่อน (Ctrl+C) ไม่งั้นมันจะรับออเดอร์ไปทำให้เคสที่ตั้งใจทดสอบเพี้ยน
