# สิ่งที่ต้องเก็บจาก Aniimo Store เอง

ร้านต้อง login ด้วย OTP ขั้นตอนเก็บจากเว็บทำแล้วในเซสชันทดสอบ (ภาษาอังกฤษ / THB) ถ้าจะเก็บชุดไต้หวัน-Mycard เพิ่ม ให้เปิด DevTools เองแล้ววางบันทึกโดย **ลบ OTP, รหัสผ่าน, cookie และ token จริงออกก่อน**

เปิด `https://www.aniimo.com/store/` แล้วเปิด DevTools → Network → เลือก Fetch/XHR → เปิด Preserve log

## เก็บตามลำดับนี้

1. สลับร้านเป็น **Region Taiwan** และสกุลเงิน **TWD** ถ้ามีตัวสลับบนหน้า บันทึกว่าปุ่มอยู่ตรงไหน และมีคำขอตอนสลับ region หรือไม่
2. Login แบบ Via Login จนผ่าน OTP อย่าส่งค่า OTP มาในแชท บันทึกเฉพาะชื่อคำขอ, URL, method และชื่อ header ที่เกี่ยวกับเซสชัน (เช่น cookie ชื่ออะไร, มี header ลายเซ็นชื่ออะไร) โดยตัดค่าลับออก
3. เข้า flow เติมเงินจนถึงจุดที่ร้านถามตัวละครหรือ UID **หยุดก่อนจ่ายเงิน** ช่องจ่ายที่โจทย์ล็อกคือ Mycard อย่ากดยืนยันจ่าย
4. จดคำขอตอนกรอก UID และเลือก server ที่ response มีชื่อตัวละคร ทั้ง URL, method, body ที่ส่ง และฟิลด์ชื่อตัวละครใน response
5. ลอง UID ผิดหรือ server ผิดหนึ่งครั้ง เก็บ status code และ body error
6. ถ้ามีคำขอถูกปฏิเสธเพราะ CAPTCHA หรือ rate limit ให้เก็บ status และข้อความ อย่าพยายามฝ่า

## ส่งกลับมาแบบนี้

แต่ละคำขอที่เกี่ยวกับตรวจตัวละครหรือสร้างเซสชันเติม ให้มี

- URL เต็มและ method
- ชื่อ header ที่ส่ง (ค่าที่เป็นความลับให้แทนด้วย `<redacted>`)
- body โครงฟิลด์ ค่า uid/server ตัวอย่างใช้ของตัวละครทดสอบได้
- response ที่ได้ชื่อตัวละคร หรือ error เมื่อ UID ผิด

ได้ชุดนี้แล้วค่อยลงมือทำ `POST /api/v1/animo/verify`
