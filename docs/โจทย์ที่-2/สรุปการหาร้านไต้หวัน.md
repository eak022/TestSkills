# สรุปการหาร้านไต้หวันและสกุลเงิน TWD

อัปเดต 9 ต.ค. 2026 ตรวจจากเบราว์เซอร์และเอกสารสาธารณะ ไม่ได้สั่งซื้อ

เป้าหมายคือหาว่าร้าน [Aniimo Store](https://www.aniimo.com/store/) มีสกุลเงิน TWD และช่อง MyCard หรือไม่ รอบแรกใช้ทางออกเน็ตไทย IP `1.47.58.127` รอบหลังใช้ทางออกเน็ตไต้หวันแล้วเปิดหน้าเลือกช่องจ่ายโดยไม่กดจ่าย

## ผลรวม

รอบแรกจากทางออกเน็ตไทยยังเป็นบาท และภาษาจีนตัวเต็มไม่เปลี่ยนสกุลเงิน  
รอบหลังต่อทางออกเน็ตไต้หวันแล้วเปิดร้านเดิม ได้สกุลเงิน TWD และหน้าเลือกช่องจ่ายมี MyCard Points รายละเอียดคำขออยู่ใน `README.md` ของโฟลเดอร์นี้

## สิ่งที่เห็นจากทางออกเน็ตไต้หวัน

เปิด `https://www.aniimo.com/store/en/` ขณะร้านรายงาน `get_ip_currency` ประเทศ TW เมือง Taipei สกุลเงิน TWD สัญลักษณ์ TWD `config` เป็น TW / TWD ภาษาหน้ายังเป็นอังกฤษ `data-region` ยังเป็น `global`

แพ็ก 300 Lumin Crystals (`com.x.aniimos.2.1.30`) ราคาเต็ม 150 เหลือ 138  
`POST /api/store/cal_final` ของแพ็กนี้จำนวน 1 ได้ส่วนลด 12 และรายการช่องจ่ายที่รวม MyCard Points

ช่องที่โจทย์ใช้คือ `channel_id` mycard, `channel_name` MyCard Points, `sub_channel_id` COSTPOINT ราคา 138 ค่าธรรมเนียมเพิ่ม 0  
เลือกช่องนี้บนหน้า Select Payment Method แล้วยอดรวมเป็น TWD 138.00 จากนั้นกด Pay Now แล้วเด้งไป `https://www.mycard520.com/MyCardPay/MemberCost` พารามิเตอร์ `MyServiceId=SPS0729407` `facid=membercoins` `TradeType=2` `ExchgCurrency=TWD` `Country=US` ส่วน `TradeInfo` ไม่บันทึก หน้านี้เป็นฟอร์ม帳號 密碼 驗證碼 ยังไม่กรอกและไม่กด登入

## สิ่งที่ยังไม่ได้ทำในรอบไทย

- ไม่ได้แก้ `game_id` หรือปลอมตัวร้านอื่น
- รอบไทยไม่ได้เปิดรายการช่องจ่ายของสกุลเงิน TWD
- บันเดิลเว็บไม่มีคำว่า MyCard การเห็นช่องนี้มาจากคำตอบ `cal_final` ของเซสชันไต้หวัน ไม่ได้มาจากซอร์สหน้าเว็บ
- ปุ่ม「立即領取」บนหน้ากิจกรรมชี้ไปโซนแลกรางวัลของ MyCard (`PrizeZone`) ไม่ได้เปิดเพราะต้องเข้าบัญชี MyCard และไม่ใช่หน้าราคาของเว็บร้าน
- กด Pay Now ของ MyCard Points แล้ว บอดี้ `place_order` อยู่ใน README ของโฟลเดอร์นี้ `openid` กับรหัสเครื่องถูกตัดออก ยังไม่กรอกบัญชี MyCard

## สิ่งที่ยังสรุปไม่ได้

เซิร์ฟเวอร์สร้าง `get_ip_currency` ด้วยสูตรอะไร ร้าน Funverse จาก IP ไทยได้รูเบิล ขณะร้าน rawprint จากทางออกเน็ตไต้หวันได้ TWD จึงยังไม่ฟันธงว่าประเทศของ IP เป็นตัวแปรเดียว

## ขั้นถัดไป

ชุด TWD และ MyCard Points ที่เห็นแล้วถูกใช้ใน `GET /api/v1/animo/packs` กับ `POST /api/v1/animo/quote` โดยไม่ยิงจ่ายจริง เมลถึง `support_hmt@aniimo.com` ยังรอคำตอบอยู่
